# 매물 글, 말 한마디로 임시저장까지 — 네이버 블로그 자동화 실습

> 이 문서만 보고 따라 하면 됩니다. 수업이 끝난 뒤에도 이 페이지를 열어놓고 쓰세요.

**Before** — 매물 글 하나 올리려면 사진 고르고, 글 쓰고, 표 만들고, 지도 넣고… 한 시간이 사라져서 자꾸 미루게 됩니다.

**뭘 던져도 알아서 알아듣고 시작합니다** — 그게 이 도구의 묘미입니다:

- 네이버 매물번호 — "매물번호 2645188091로 글 써줘"
- 매물 페이지 링크 — 네이버부동산이든 다른 매물 사이트든 주소 그대로 붙여넣기
- 말로 설명 — "파주 창고 매매 23억, 180평, 층고 8.5미터…"
- 사진 폴더 — 끌어다 놓기만
- 따로따로 와도 됩니다 — 정보는 말로, 사진은 폴더로 주면 알아서 한 판으로 합칩니다

**After** — 매물을 두 줄로 말하면 AI가 임시저장까지 해놓습니다. 사장님은 읽어보고 발행 버튼만 누르면 끝.

## 1. 오늘 얻어갈 것

말 몇 마디만 하면, AI가 이런 글을 **네이버 블로그 임시저장함까지** 넣어줍니다.

[이미지: 01-result-top.png — 완성 글 상단. 제목·도입·썸네일이 자동으로 만들어진 모습]

- 제목과 본문, 매물에 맞는 챕터 구성까지 자동
- 썸네일과 전화 상담 배너를 **AI가 새로 그려서** 넣음 (디자인 외주 불필요)
- 보증금·면적 같은 숫자는 표로 정리

[이미지: 02-result-table.png — 핵심 조건이 표로 정리된 모습]

글 맨 아래에는 전화 배너가 붙고, **손님이 휴대폰에서 배너나 전화번호를 탭하면
바로 사장님 번호로 전화가 걸립니다.**

[이미지: 03-result-bottom.png — 전화 배너와 전화 링크. 배너 오른쪽 위 고리 아이콘이 "탭하면 전화" 표시]

### 글 위아래 이미지도 AI가 그립니다

글 맨 위 **썸네일**과 맨 아래 **전화 상담 배너**는 사장님이 만드는 게
아닙니다. 사무소 정보(이름·전화)와 매물명만으로 코덱스에 내장된 이미지
생성 기능(imagen)이 자동으로 그립니다 — 별도 프로그램·디자인 외주·추가
결제 없음. 전화 배너는 한 번 만들면 다음 글부터 재사용합니다. 실제 생성물:

썸네일 — 글 맨 위, 목록에서 눈에 띄는 얼굴:

[이미지: examples/example-thumbnail.png]

전화 상담 배너 — 글 맨 아래, 손님이 탭하면 바로 전화:

[이미지: examples/example-cta-banner.png]

**걸리는 시간**: 입력 2분 → 임시저장까지 자동. 발행 버튼은 사장님이 누릅니다.

## 코덱스 화면으로 보는 실제 순서

### ① 부르기

설치가 끝나면 채팅창에 `$매`만 쳐도 자동완성에 **매물블로그**가 뜹니다.
선택하고 매물 이야기를 시작하면 됩니다 — `$` 없이 그냥 "매물 블로그 글
써줘"라고 말해도 알아듣습니다.

[스크린샷 필요: $매물블로그 자동완성이 뜬 코덱스 입력창]

### ② 처음 한 번만 — 세팅되는 화면

첫 실행에서만 두 가지가 지나갑니다:

- 사무소 정보를 말했다면 "설정에 저장해뒀습니다. 다음부터는 안
  물어봅니다" 한 줄이 지나가고, 안 말했다면 시작할 때 딱 한 번 물어봅니다
  (사무소명·성함·전화·블로그 아이디)
- **네이버 로그인 창이 자동으로 뜹니다** → 그 창에서 로그인만 하면 창이
  닫히고 하던 작업이 이어집니다 (`로그인 상태 유지` 체크!)

[스크린샷 필요: 사무소 정보를 저장했다고 알리는 코덱스 화면]

### ③ 그다음은 순서대로 알아서

코덱스 화면에 진행 상황이 한 줄씩 올라옵니다. 실제 흐름 그대로:

"매물 사실·사진 9장 수집 완료" → "썸네일·전화 배너 생성" → "원고 작성,
검사 통과" → "네이버에 옮기는 중 — 브라우저 창이 잠깐 뜹니다 (건드리지
마세요)" → **"임시저장 완료 — 글 33개 → 34개"**

[스크린샷 필요: 진행 보고가 순서대로 쌓인 코덱스 화면]

마지막 보고가 **SAVED**면 성공입니다. 네이버 임시저장함을 열어 확인하고
발행하면 끝 — 자세한 건 아래 5번 섹션에 있습니다.

## 3. 설치 — 코덱스에게 시키면 끝

터미널 명령을 외울 필요 없습니다. 코덱스를 열고 아래를 **그대로 복사해서
붙여넣으세요**:

```
이 깃허브 스킬을 설치해줘: https://github.com/Dr-Min/naver-realtor-blog-pro
혹시 git이나 Node.js가 컴퓨터에 없으면 그것부터 설치하게 도와줘.
적당한 폴더에 받아서 npm install 하고 npx playwright install chromium까지 해줘.
그리고 저장소 안의 naver-realtor-blog-pro 폴더(SKILL.md가 있는 폴더)를
코덱스 스킬 폴더(~/.codex/skills/)에 매물블로그라는 이름으로 연결해줘.
끝나면 스킬이 잡히는지 확인해줘.
```

**설치하는 동안 뭘 내려받나요** (처음 한 번, 5–10분):

- **깃허브에서 스킬 본체** — 글 쓰는 순서가 적힌 설명서와 네이버에 옮겨
  적는 전송 프로그램이 들어있는 저장소. 업데이트도 여기서 받습니다
- **전송 프로그램 부품** (npm install) — 전송 프로그램의 부속품
- **전용 브라우저** (playwright chromium) — 전송 프로그램이 조종하는
  도구용 크롬. 사장님 크롬과 완전히 분리돼 있고, 용량이 커서(수백 MB)
  이 단계가 제일 오래 걸립니다 — 멈춘 것처럼 보여도 내려받는 중입니다

[스크린샷 필요: 코덱스에 위 문장을 붙여넣은 화면]

**✅ 성공 확인**: 코덱스에 "매물블로그 스킬 뭐 하는 거야?"라고 물어보세요. 스킬 소개가 나오면 설치
완료입니다. 이제 채팅창에 `$매`만 쳐도 자동완성에 매물블로그가 뜹니다.

[스크린샷 필요: 스킬 소개가 나온 코덱스 화면]

## 4. 첫 글 만들기 — 한 번에 다 넣으면 안 물어보고 끝까지 갑니다

### 붙여넣기 템플릿

```
블로그 글 만들어서 임시저장까지 해줘.
매물: ______ (네이버 매물번호 / 매물 페이지 주소 / 말로 설명, 아무거나)
사진: ______ (사진 폴더 위치. 네이버 매물번호를 줬으면 생략 — 알아서 다 가져옵니다)
블로그: ______ (블로그 아이디, 처음 한 번만)
나는 ______ 공인중개사 ______(이름)이고 상담 전화는 ______ (처음 한 번만)
```

### 실제 예시 ① — 말로 설명

```
파주에 창고 매물 하나 잡았는데 블로그 글 만들어서 임시저장까지 해줘.
공장·창고 매매고 23억. 파주시 상지석동이고 운정역 근처야.
전용 180평, 대지 497평, 단층에 층고 8.5미터.
2020년 사용승인 받은 준신축이고 40피트 트레일러 들어가.
사진은 이 폴더에 있어: (사진 폴더를 끌어다 놓으세요)
내 블로그 아이디는 ______이야.
```

### 실제 예시 ② — 네이버 매물번호가 있으면 이게 제일 짧습니다

```
매물번호 2645188091 이걸로 블로그 글 만들어서 임시저장까지 해줘.
내가 중개하는 매물이야.
```

### 실제 예시 ③ — 매물 페이지 링크 붙여넣기

```
이 매물 링크로 블로그 글 만들어서 임시저장까지 해줘. 내가 중개하는 매물이야.
https://fin.land.naver.com/articles/2645188091
```

네이버부동산 상세 페이지 주소든 다른 매물 사이트 주소든 됩니다 —
페이지에 적힌 사실과 사진을 그대로 가져와서 씁니다.

💡 내 매물번호는 네이버부동산 **매물 상세 페이지의 '기본 정보' 표 맨 아래**
(입주가능일 다음 줄)에 있습니다. 번호만 주면 가격·면적 같은 사실과 **등록된
갤러리 사진 전부**를 알아서 가져옵니다.

💡 링크가 더 편하면 링크로 — 네이버부동산 상세 페이지 주소를 복사해
붙여도 똑같이 작동합니다. 다른 매물 사이트 링크도 됩니다 (그 페이지에
적힌 사실만 가져옵니다).

### 중간에 이 창이 뜨면 — 네이버 로그인 한 번

처음 실행하면 도구가 로그인이 필요한 걸 알아채고 브라우저 창을 띄워줍니다.
**그 창에서 평소처럼 로그인만 하세요. `로그인 상태 유지` 꼭 체크!**
약 2주간 유지되므로 그동안은 다시 로그인할 일이 없습니다.

> 것뿐이고, 도구는 묻지도 저장하지도 않습니다.

[스크린샷 필요: 코덱스가 진행 상황을 보고하는 화면 — "원고 작성 완료, 전송 중…" 등]

## 5. 확인하고 발행하기 — 마지막은 사장님 몫

끝나면 코덱스가 "임시저장 완료 (글 개수 N개 → N+1개)"라고 보고합니다.
네이버 블로그 **글쓰기 화면 오른쪽 위 `저장 N` 숫자**를 누르면 임시저장
목록이 열립니다:

[이미지: 05-draft-list.png — 임시저장 목록. 방금 저장된 글이 맨 위에 있습니다]

글을 열고 세 가지만 확인하세요:

1. **숫자** — 가격·면적이 맞는지 (AI는 말한 사실만 쓰지만, 최종 책임은 발행자)
2. **사진** — 순서와 자리가 마음에 드는지
3. **전화번호** — 배너와 글 끝의 번호가 내 번호인지

고칠 게 있으면 그 자리에서 고치고, **발행 버튼을 누르세요.** 이 도구는 발행
버튼을 누르는 코드 자체가 없습니다 — 글이 세상에 나가는 건 사장님 손으로만.

발행 후 휴대폰에서 글을 열어 전화 배너를 한 번 탭해보세요 — 내 번호로
전화가 걸리면 전부 정상입니다.

## 6. 이 도구가 절대 하지 않는 것 3가지

1. **발행하지 않습니다** — 누르는 버튼은 임시저장 하나뿐
2. **비밀번호를 다루지 않습니다** — 로그인은 언제나 사장님이 직접
3. **지어내지 않습니다** — 말한 사실과 매물 페이지의 사실만. 모르는 값은
   비우거나 "확인 필요"로 쓰지, 그럴듯하게 채우지 않습니다

## 7. 자주 묻는 질문

**Q. "다시 로그인해 주세요"라고 떠요.**
2주가 지나 로그인이 만료된 겁니다. 도구가 띄워주는 창에서 로그인만 다시
하면 됩니다 (`로그인 상태 유지` 체크).

**Q. 같은 글이 두 개 생겼어요.**
같은 매물을 다시 시키면 정상적으로 하나 더 생깁니다. 저장 시각이 최신인
걸 쓰고, 나머지는 직접 지우면 됩니다 (도구는 삭제 버튼을 절대 안 누릅니다).

**Q. 사진이 한 장 빠졌대요.**
보고에 어떤 사진이 왜 빠졌는지 적혀 있습니다. 그 사진만 편집기에서 직접
넣으면 됩니다.

**Q. 매물번호가 어디 있는지 모르겠어요.**
네이버부동산에서 내 매물 상세 페이지를 열고 아래로 내리면 '기본 정보' 표
맨 아래에 있습니다. 네이버에 광고를 안 올린 매물은 번호가 없습니다 —
그때는 말로 설명하거나 사진 폴더로 하면 됩니다.

**Q. 사진마다 뭘 찍은 건지 적어줘야 하나요?**
아니요. AI가 사진을 한 장씩 직접 열어 보고 외관인지 내부인지 화장실인지
알아본 다음, 해당 문단 옆에 배치합니다. 적어주면 그게 우선되긴 합니다.
