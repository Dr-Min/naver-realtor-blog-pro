# 매물 글, 말 한마디로 임시저장까지 — 네이버 블로그 자동화 실습

> 이 문서만 보고 따라 하면 됩니다. 수업이 끝난 뒤에도 이 페이지를 열어놓고 쓰세요.

---

## 1. 오늘 얻어갈 것

말 몇 마디만 하면, AI가 이런 글을 **네이버 블로그 임시저장함까지** 넣어줍니다.

[이미지: 01-result-top.png — 완성 글 상단. 제목·도입·썸네일이 자동으로 만들어진 모습]

- 제목과 본문, 매물에 맞는 챕터 구성까지 자동
- 썸네일과 전화 상담 배너를 **AI가 새로 그려서** 넣음 (디자인 외주 불필요)
- 보증금·면적 같은 숫자는 표로 정리

[이미지: 02-result-table.png — 핵심 조건이 표로 정리된 모습]

글 맨 아래에는 전화 배너가 붙고, **손님이 휴대폰에서 배너나 전화번호를 탭하면
바로 사장님 번호로 전화가 걸립니다.**

[이미지: 03-result-bottom.png — 전화 배너와 전화 링크. 배너 오른쪽 위 고리 아이콘이 "탭하면 전화" 표시]

**걸리는 시간**: 입력 2분 → 임시저장까지 자동. 발행 버튼은 사장님이 누릅니다.

## 4. 첫 글 만들기 — 한 번에 다 넣으면 안 물어보고 끝까지 갑니다

### 붙여넣기 템플릿

```
블로그 글 만들어서 임시저장까지 해줘.
매물: ______ (네이버 매물번호 / 매물 페이지 주소 / 말로 설명, 아무거나)
사진: ______ (사진 폴더 위치. 네이버 매물번호를 줬으면 생략 — 알아서 다 가져옵니다)
블로그: ______ (블로그 아이디, 처음 한 번만)
나는 ______ 공인중개사 ______(이름)이고 상담 전화는 ______ (처음 한 번만)
```

### 실제 예시 ① — 말로 설명

```
파주에 창고 매물 하나 잡았는데 블로그 글 만들어서 임시저장까지 해줘.
공장·창고 매매고 23억. 파주시 상지석동이고 운정역 근처야.
전용 180평, 대지 497평, 단층에 층고 8.5미터.
2020년 사용승인 받은 준신축이고 40피트 트레일러 들어가.
사진은 이 폴더에 있어: (사진 폴더를 끌어다 놓으세요)
내 블로그 아이디는 ______이야.
```

### 실제 예시 ② — 네이버 매물번호가 있으면 이게 제일 짧습니다

```
매물번호 2645188091 이걸로 블로그 글 만들어서 임시저장까지 해줘.
내가 중개하는 매물이야.
```

💡 내 매물번호는 네이버부동산 **매물 상세 페이지의 '기본 정보' 표 맨 아래**
(입주가능일 다음 줄)에 있습니다. 번호만 주면 가격·면적 같은 사실과 **등록된
갤러리 사진 전부**를 알아서 가져옵니다.

### 중간에 이 창이 뜨면 — 네이버 로그인 한 번

처음 실행하면 도구가 로그인이 필요한 걸 알아채고 브라우저 창을 띄워줍니다.
**그 창에서 평소처럼 로그인만 하세요. `로그인 상태 유지` 꼭 체크!**
약 2주간 유지되므로 그동안은 다시 로그인할 일이 없습니다.

[이미지: 04-login-window.png — 이 창이 뜨면 로그인만 하면 됩니다]

> 🔒 아이디·비밀번호는 도구를 거치지 않습니다. 네이버 화면에 직접 입력하는
> 것뿐이고, 도구는 묻지도 저장하지도 않습니다.

[스크린샷 필요: 코덱스가 진행 상황을 보고하는 화면 — "원고 작성 완료, 전송 중…" 등]

## 5. 확인하고 발행하기 — 마지막은 사장님 몫

끝나면 코덱스가 "임시저장 완료 (글 개수 N개 → N+1개)"라고 보고합니다.
네이버 블로그 **글쓰기 화면 오른쪽 위 `저장 N` 숫자**를 누르면 임시저장
목록이 열립니다:

[이미지: 05-draft-list.png — 임시저장 목록. 방금 저장된 글이 맨 위에 있습니다]

글을 열고 세 가지만 확인하세요:

1. **숫자** — 가격·면적이 맞는지 (AI는 말한 사실만 쓰지만, 최종 책임은 발행자)
2. **사진** — 순서와 자리가 마음에 드는지
3. **전화번호** — 배너와 글 끝의 번호가 내 번호인지

고칠 게 있으면 그 자리에서 고치고, **발행 버튼을 누르세요.** 이 도구는 발행
버튼을 누르는 코드 자체가 없습니다 — 글이 세상에 나가는 건 사장님 손으로만.

발행 후 휴대폰에서 글을 열어 전화 배너를 한 번 탭해보세요 — 내 번호로
전화가 걸리면 전부 정상입니다.

---

## 6. 이 도구가 절대 하지 않는 것 3가지

1. **발행하지 않습니다** — 누르는 버튼은 임시저장 하나뿐
2. **비밀번호를 다루지 않습니다** — 로그인은 언제나 사장님이 직접
3. **지어내지 않습니다** — 말한 사실과 매물 페이지의 사실만. 모르는 값은
   비우거나 "확인 필요"로 쓰지, 그럴듯하게 채우지 않습니다

## 7. 자주 묻는 질문

**Q. "다시 로그인해 주세요"라고 떠요.**
2주가 지나 로그인이 만료된 겁니다. 도구가 띄워주는 창에서 로그인만 다시
하면 됩니다 (`로그인 상태 유지` 체크).

**Q. 같은 글이 두 개 생겼어요.**
같은 매물을 다시 시키면 정상적으로 하나 더 생깁니다. 저장 시각이 최신인
걸 쓰고, 나머지는 직접 지우면 됩니다 (도구는 삭제 버튼을 절대 안 누릅니다).

**Q. 사진이 한 장 빠졌대요.**
보고에 어떤 사진이 왜 빠졌는지 적혀 있습니다. 그 사진만 편집기에서 직접
넣으면 됩니다.

**Q. 매물번호가 어디 있는지 모르겠어요.**
네이버부동산에서 내 매물 상세 페이지를 열고 아래로 내리면 '기본 정보' 표
맨 아래에 있습니다. 네이버에 광고를 안 올린 매물은 번호가 없습니다 —
그때는 말로 설명하거나 사진 폴더로 하면 됩니다.

**Q. 사진마다 뭘 찍은 건지 적어줘야 하나요?**
아니요. AI가 사진을 한 장씩 직접 열어 보고 외관인지 내부인지 화장실인지
알아본 다음, 해당 문단 옆에 배치합니다. 적어주면 그게 우선되긴 합니다.
